## Machine-Specific Setup

### On a new machine:
```bash
# 1. Clone and setup
git clone https://github.com/amodmulay-ltts/ai-local-sdlc.git
cd ai-local-sdlc

# 2. Backend
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -e ".[dev]"
python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000 --reload

# 3. Frontend (in another terminal)
cd frontend
npm install
npm run dev

# 4. Database (if needed for full integration)
docker-compose up -d
```

### Environment Variables
- Copy `.env.example` to `.env` (already configured for local dev)
- For Anthropic: Set `ANTHROPIC_API_KEY=sk-ant-...`
- For Ollama: Ensure `OLLAMA_BASE_URL=http://localhost:11434`

## Known Issues & Workarounds

- **Tailwind dark mode:** Had to use `@custom-variant` in v4; class-based selector now works
- **Duplicate API servers:** If port 8000 is stuck, run `lsof -i :8000` (Unix) or `netstat -ano | find ":8000"` (Windows) and kill old processes
- **Theme toggle in browser:** Hard-refresh (`Ctrl+Shift+R`) after code changes to clear Next.js cache
